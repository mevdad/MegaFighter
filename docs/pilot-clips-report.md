# Пилот клипов Терракса: отчёт

Пилот (DECISIONS §1, §3): `fighting_idle`, `jab`, `martelo_2`, `cross_punch`, собраны в `public/models/warrior3.glb`
скриптом `scripts/build-clips.mjs` прямо из FBX (Node, без Blender). Воспроизведение: `npm run build:clips`,
`npm run verify:clips`, `node scripts/compare-clips.mjs`, картинки `node scripts/clips-audit/pilot_shoot.mjs`.

## Клипы

| id | FBX | кадры FBX (включительно) | кадров | длительность, с | loop | rootLock |
|---|---|---|---:|---:|---|---|
| fighting_idle | Fighting_Idle | 0-101 (кадр 102 = дубль кадра 0, отброшен) | 102 | 3,3667 | да | z, 0 |
| jab | Jab | 11-26 | 16 | 0,5000 | нет | z, 0 |
| martelo_2 | Martelo_2 | 3-35 | 33 | 1,0667 | нет | z, 1 |
| cross_punch | Cross_Punch | 24-45 | 22 | 0,7000 | нет | z, 0 |

Время ключа = (кадр - start)/30, клип начинается с t = 0 (сдвига +1/30 с, как у Blender-сборки, нет).
Каналы: rotation у всех 41 кости, translation только у Hips, каналов scale нет, интерполяция LINEAR.
Loop-нюанс: у GLB-клипа длительность равна времени последнего ключа (101/30 с), движок при зацикливании переходит с кадра 101
на кадр 0 мгновенно, поэтому период 101 кадр вместо 102 (на 1/30 с короче, около 1%). Дубль кадра 102 по заданию не хранится.

## Проверка FK против FBX (допуск 1 мм)

Ошибка кости = |положение относительно Hips по GLB - положение относительно Hips по FBX|, 41 кость (40 без Hips), каждый кадр.

| jab | 16 | 0,236 | 0,098 | LeftHandThumb4 (15) | 30,80 | 0,0008 |

Максимум 0,28 мм при допуске 1 мм. Остаток это разница округлений длин костей: у «Without Skin» FBX translation костей округлён
до 4 знаков, у меш-скелета нет (до 0,08 мм на кость, копится по цепочке до пальцев). Ошибка вращений нулевая в пределах float32.

### Hips: абсолютное смещение и почему

Скелет «Without Skin» FBX и меш-скелет одинаковы по длинам костей (до 0,08 мм), но Hips в позе покоя стоит в разных точках:

| | Hips покоя (x; y; z), м |
|---|---|
| меш-скелет (GLB, мир) | (0; 0,56059; 0,03048) |
| FBX клипа (Fighting_Idle, Jab, Martelo_2, Cross_Punch, одинаково у всех четырёх) | (0; 0,56500; 0) |
| D = меш - FBX | (0; -0,00441; +0,03048), |D| = 30,8 мм |

Выбрано `t_мир = t_fbx + D` для каждого ключа Hips. Это сохраняет относительное движение таза (разности ключей) и совмещает позу
покоя клипа с позой покоя меша: ступни стоят на той же высоте, что откалибровал `TUNING` (groundOffset 0), таз на z = +0,030 как
у меша (меш центрирован по Z). Без сдвига таз был бы на 4,4 мм выше и на 30,5 мм позади меша. Поэтому «абсолютное смещение Hips
vs FBX» везде равно |D| = 30,80 мм, невязка после D нулевая. У martelo_2 после лока 324,63 мм: Hips зафиксирован по мировому Z
на значении первого ключа (кадр 3), ход таза вперёд 0,36 м срезан.
В локальную систему узла: родитель Armature повёрнут на +90° по X, мировой вектор w -> локальный (wx; wz; -wy), вращение Hips
= Armature⁻¹ · PreRotation · R(кривая) (PreRotation Hips в FBX нулевой).

## Старые клипы (Blender) против новых (FBX)

Положения костей относительно Hips на одинаковых кадрах FBX, мм (старый минус новый). Старый ключ k лежит на t = (k+1)/30,
то есть GLB-кадр k = кадр k FBX; у нового локальный кадр j = кадр FBX start+j. «После rootLock» от лока позиции относительно
Hips не зависят (разница 0,0014 мм), лок двигает только Hips.

### Вывод

Ожидание аудита (AUDIT_CLIPS §10.1) подтверждается: у kick_high кисти отличаются до 293 мм (в среднем 201), локти до 137 мм,
стопы до 65 мм; у punch_heavy кисти до 143 мм, локти до 135 мм, стопы до 64 мм (диапазон 0,15-0,3 м по кистям и локтям).
Голова, позвоночник и шея совпадают (0 мм): перекос только в руках и ногах, то есть в 24 костях с ненулевой позой по умолчанию.
Вынос кулака у cross_punch: 0,314 м (старый) против 0,354 м (FBX), кадр 34: оба значения подтверждаются.
Хай-кик: у старого стопа по высоте и выносу короче, нога бьёт заметно ниже (картинка `docs/pilot-clips-compare.png`).
