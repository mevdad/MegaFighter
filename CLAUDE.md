# 2.5D-файтинг (веб, TypeScript)

Вид сбоку, 3D-модели Mixamo, логика в 2D (X, Y; Z зафиксирована).
Рендер: PlayCanvas.

## Инварианты (не нарушать)
- `sim/` не импортирует движок и DOM. Рендер только читает состояние.
- Фиксированный шаг 60 тиков/сек, отдельно от рендера.
- Детерминизм: в `sim/` нет Math.random, Date.now, performance.now.
- Состояние симуляции сериализуется одним plain-объектом.
- Вход симуляции: битовые маски ввода по игрокам на каждый тик.
- Удары описываются данными (frame data в JSON/TS), не кодом.
- Хитбоксы: только AABB в симуляции, физический движок не использовать.
- Анимации Mixamo In Place, поза сэмплируется по игровому кадру.
- Разворот персонажа: поворот на 180° по Y, не отрицательный scale.
- Константы (скорости, гравитация, размеры) только в конфиге.
